## Review and Rename Proposal — IR Remote Capabilities (SA)

**Status:** PROPOSED. Nothing applied to the model.
**Model basis:** `tkomarOSP/SmartRoboticCar`, `master`, commit `d6654d6`, as reviewed in `model_log_book/obs-0001`.
**Sources:** SA capability names collected in that review; the manufacturer page registered as `artifacts/note-0002`.
**Limits:** names and UUIDs only. A later attempt to read descriptions and relationships failed because the GitHub authorization for the model repo had expired, so no capability descriptions, involvements or relations were inspected.

### Naming conventions applied
1. **Verb phrase, Title Case**, describing what the car can do (the pattern `Operate with a Remote` already uses).
2. **Say "IR Remote" for IR-specific capabilities.** The model already uses that term for the PA component `IR Remote`, the chain `IR Remote Control;`, the function `Process IR Remote Command` and the requirement `IR Remote Control`. A bare "Remote" is ambiguous because the model also has the app rocker remote (`Rocker Remote`, chain `App Rocker Remote Control`).
3. **Do not add "IR Remote" to capabilities that are not tied to one input** (drive, turn, stop, the three modes): the means belongs in the functional chains, not the capability name.
4. **Use the manual's vocabulary** for the modes (hyphenated Line-Tracking, Obstacle-Avoidance, Auto-Follow).
5. **Qualify "threshold"** as the line-tracking threshold, which is what the manual's keys adjust.
6. **Keep the Increase / Reduce / Restore Default triplet parallel** for both threshold and speed.
7. Fix spelling.

### Open questions for the model owner
1. What does `Restore Defaults` cover today (threshold, speed or both)? The proposed rename assumes threshold only.
2. Are the drive, turn and stop capabilities also used by the app rocker path? If they are IR-only, add "with IR Remote" instead of leaving them neutral (convention 3).
3. Capabilities not reviewed here that may overlap: `Control Modes` (`24a9c729-edef-494a-bb36-82e7ec011603`), `Rocker Remote`, `Ap Control`, `Standbye`.
4. Mode style: this proposal keeps the manual's noun form ("... Mode"). A verb form (Track Line, Avoid Obstacles, Follow Automatically) is the alternative if a fully verb-based set is preferred.
