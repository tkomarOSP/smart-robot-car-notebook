## IR Remote Controller — Key Map and Usage (Elegoo manual, page 26)

### Artifact
- **Name and type:** Manufacturer user-manual page, "Control the Smart Robot Car using the IR remote control" (page 26). Reference / source document, not derived from the model.
- **Source:** Elegoo Smart Robot Car manual; the page points readers to Elegoo's download site for tutorials.
- **Location:** Supplied by the model owner as an image in a Claude chat on 2026-11-05. **The image file itself is not stored in this notebook**; this entry is the index card and a transcription of the facts. If the page needs to stay available, keep the original with the project files and note where here.
- **Purpose:** Authoritative description of how an operator drives and configures the car with the supplied IR remote. It is the source for the IR remote operational scenario in the model (SA capabilities, the IR remote functional chain, and the PA IR remote and receiver).

### Content (paraphrased)

**Setup notes**
- The control program is already loaded on the car at the factory, so no upload is needed unless the user has modified the code; in that case it must be re-uploaded using Elegoo's tutorial.
- The remote ships with a transparent plastic insulating strip on its rear that must be removed before first use.
- The line-tracking sensors are strongly affected by ambient conditions. If tracking performs poorly, the remote can be used to adjust the sensor threshold to suit the environment.

**Drive commands (shown on the first remote diagram):** Forward, Turn Left, Backward and Turn Right are mapped to the four arrow keys.

**Mode commands (shown on the second remote diagram):** Line-tracking mode, Stop, Obstacle-avoidance mode and Auto-follow mode. The diagram connects these to keys in the arrow/OK cluster and the number pad. *The exact key for each mode, and in particular Auto-follow, is not reliably legible in the supplied image; confirm against the original page before relying on it.*

**Numeric configuration keys (stated explicitly on the page)**

| Key | Function |
|---|---|
| 4 | Increase the (line-tracking) threshold value |
| 5 | Restore the initial default threshold value |
| 6 | Reduce the threshold value |
| 7 | Increase speed |
| 8 | Restore the initial default speed |
| 9 | Reduce speed |
