Repurposing it closes that gap with the Increase / Reduce / Restore Default pattern now parallel for the threshold (`Increase Line-Tracking Threshold`, `Reduce Line-Tracking Threshold`, `Restore Default Line-Tracking Threshold`) and for speed.
