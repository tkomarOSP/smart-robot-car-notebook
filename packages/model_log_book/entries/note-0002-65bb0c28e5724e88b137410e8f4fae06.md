## Issue — SA capabilities do not cover all IR remote configuration commands

**Found by:** comparing the Elegoo manual's IR remote page (registered as `artifacts/note-0002`) against the model as reviewed in `model_log_book/obs-0001` (commit `d6654d6`, `master`).

**Finding:**
- The manual defines six numeric configuration commands: increase threshold, restore default threshold, reduce threshold, increase speed, restore default speed, reduce speed.
- The SA capability set has `Increase Threshold`, `Increase Speed`, `Restore Default Speed` and `Reduce Speed`, but **no `Reduce Threshold`**.
- `Restore Defaults` (`7a5f4bce-ef81-41d3-b0fb-505c35ea14b7`) is ambiguous: it may stand for the default-threshold restore, or for both defaults.

**Layer:** SA (capabilities). Downstream effect on LA and PA not assessed.

**Proposed resolution (not started, needs owner decision):**
1. Decide whether `Reduce Threshold` is intentionally out of scope.
2. If not, add it as an SA capability and relate it to the IR remote functional chain.
3. Clarify or split `Restore Defaults` against the separate threshold and speed restore commands.
4. Log the change here with the commit and re-verify the SA layer.

**Status:** open. Comparison was by element name only; realization and allocation links were not inspected.
